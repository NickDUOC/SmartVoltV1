# SmartVolt: Control de Asistencia en Faena

## Descripción
Aplicación móvil desarrollada en Kotlin para el control de asistencia y marcaje correcto de operarios en terreno para Smart-Volt, con soporte offline.

## Funcionalidades
Navegación mediante splashscreen
Marcaje con confirmación de gps real
Persistencia de datos locales y actualización con el servidor
Historial de registros
